
Входные артефакты:
Описание функциональных требований:
•	Конвертировать рубли в валюту, которую выбирает пользователь
•	Пользователь сам вводит количество рублей
•	Поддержка 4 разных валют
•	Взятие комиссии банком 5%

Перечень поддерживаемых сценариев использований:
•	Пользователь ввел количество рублей => выбрал валюту которые ему нужно

Сведение о целевой платформе и окружении:
•	Люди среднего возраста, которым по тем или иным причинам понадобилось узнать, узнать сколько денег у них в другой валюте
